# Torres em Comum

**Construção participativa do Regimento Interno do Torres de Olinda**

Projeto para organizar a leitura da minuta do Regimento Interno, registrar manifestações por dispositivo e gerar um resumo individual para formalização pelos canais definidos pelo condomínio.

## Princípios

- Não substitui a Assembleia Geral.
- Não transforma ausência de resposta em concordância.
- Preserva o texto original da minuta.
- Permite: Concordo, Alterar, Excluir, Observação e Não quero me manifestar a respeito.
- Exibe dados públicos apenas de forma agregada.

## Stack inicial

Vite + React + TypeScript. O MVP será preparado para persistência em Supabase/PostgreSQL, geração de PDF e posterior upload do documento assinado.
